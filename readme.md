# Waydroid on Ubuntu based Linux Operating Systems: Installation Guide

A guide to installing and fixing Waydroid on Ubuntu.

This repo exists because most tutorials are incomplete and ignore issues
like 0.0 kbps download speedsand broken networking.

## Supported Systems
- Ubuntu 22 or above systems
- Kernel 5.15+
- Intel VT-x / AMD-V enabled
- x86/64 CPUs only
